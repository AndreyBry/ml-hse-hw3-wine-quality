Приложение для оценки качества вина. Хорошее вино имеет качество не ниже 7.
Используется сохранённая логистическая регрессия с масштабированием признаков;
при запуске приложения обучение не выполняется.

Проверенная версия Python: 3.13.13. Из папки wine_app выполните:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

В Windows виртуальное окружение активируется командой `.venv\Scripts\activate`.
После запуска откройте адрес, который напечатает Streamlit, обычно
http://localhost:8501. Для остановки нажмите Ctrl+C в терминале.
Файлы model.joblib, config.json и test.csv должны находиться рядом с app.py.
Пути строятся от расположения app.py, поэтому запуск из другой папки также работает.

Во вкладке «Одно вино» задаются 11 числовых признаков и цвет вина.
Диапазоны ввода и начальные значения взяты из test.csv: минимум, максимум и медиана.
Порог в боковой панели общий для оценки одного вина, тестовых метрик и пакетного
предсказания; начальное значение берётся из config.json.
Точки на ROC- и PR-кривых соответствуют выбранному порогу.

Для пакетного предсказания нужен CSV в UTF-8 с запятой в качестве разделителя,
с 12 признаками и без target. Пример можно скачать в приложении.
is_red принимает 0 для белого вина и 1 для красного. Пропуски, бесконечные и
нечисловые значения, отсутствующие, лишние и повторяющиеся столбцы отклоняются
с сообщением об ошибке. Результат содержит probability и prediction, где 1
означает включение вина в подборку при текущем пороге, а 0 — исключение.

Для модели применяется st.cache_resource: модель загружается один раз и остаётся
одним общим объектом для повторных запусков скрипта и пользовательских сессий.
Приложение использует её только для чтения и предсказаний. st.cache_data хранит
таблицы и вероятности в сериализованном виде и возвращает отдельные копии, чтобы
изменение данных в одной сессии не затрагивало остальные. Аргумент _model исключён
из хеширования; кэш вероятностей определяется таблицей признаков. Порог не входит
в вычисление вероятностей: при его изменении пересчитываются только решения и
метрики. Без декоратора joblib.load повторно читает модель с диска при каждом
действии пользователя. После замены файлов модели или данных перезапустите сервер.

Описание кэширования: [st.cache_resource](https://docs.streamlit.io/develop/api-reference/caching-and-state/st.cache_resource)
и [st.cache_data](https://docs.streamlit.io/develop/api-reference/caching-and-state/st.cache_data).
